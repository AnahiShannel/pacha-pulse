# Pacha Pulse

Hola, quiero que hagas la interfaz de una pagina web, tiene las siguientes caracteristicas: # PACHA PULSE — Cozy AgriTech Dashboard Design

Actúa como un equipo senior de Product Designers, UX/UI Designers, expertos en diseño de videojuegos cozy, ilustradores digitales y especialistas en interfaces SaaS.

Quiero que diseñes una plataforma web llamada **PACHA PULSE**, desarrollada para el NASA Space Apps Challenge 2026, dentro del desafío "Field Shift: Adapting Farms with NASA Data".

Tu tarea es diseñar una experiencia visual completa, intuitiva, atractiva y navegable.

**REFERENCIA VISUAL PRINCIPAL:**

Utiliza la imagen de referencia proporcionada por el usuario como inspiración principal de diseño.

Quiero conservar su estilo visual:
- Dashboard ilustrado con estética cozy.
- Barra lateral verde bosque.
- Encabezado panorámico con paisaje natural.
- Tarjetas color crema con bordes redondeados.
- Ilustraciones pequeñas de plantas, árboles, animales y herramientas.
- Distribución organizada en paneles.
- Apariencia cálida, amigable y ligeramente gamificada.
- Sensación de estar administrando y cuidando un pequeño mundo natural.

No copies personajes, logotipos ni elementos protegidos de la referencia. Crea una identidad original basada en agricultura andina.

IMPORTANTE: No quiero un dashboard empresarial convencional ni una landing page genérica. Quiero una plataforma completa que visualmente se sienta como un videojuego de gestión agrícola combinado con una herramienta científica profesional.

---

# 1. IDENTIDAD DE PACHA PULSE

Nombre: PACHA PULSE.

Eslogan: "Conectando la tierra con el futuro".

Concepto: una plataforma que ayuda a los agricultores de la sierra peruana a comprender las condiciones de sus parcelas, planificar sus cultivos, explorar escenarios climáticos y adoptar prácticas agrícolas sostenibles utilizando información de observación terrestre de NASA.

Público objetivo:
- Pequeños y medianos agricultores.
- Agricultores de la región Junín.
- Personas con conocimientos tecnológicos básicos.
- Usuarios que necesitan información sencilla y visual para tomar decisiones agrícolas.

La experiencia debe transmitir:
- Naturaleza.
- Tranquilidad.
- Innovación.
- Confianza.
- Sostenibilidad.
- Cercanía con los agricultores.

# 2. SISTEMA VISUAL

## Paleta de colores

Utiliza una paleta inspirada en paisajes andinos y elementos naturales.

- Verde bosque oscuro: #344C36.
- Verde musgo: #607B4F.
- Verde salvia: #A5B68C.
- Verde claro: #DCE6CF.
- Crema principal: #F5F0DF.
- Beige suave: #EAE1CA.
- Marrón tierra: #907552.
- Amarillo cosecha: #D9B65B.
- Blanco cálido: #FFFCF3.

Los colores deben ser suaves, cálidos y armoniosos.

## Tipografía

Combinar:
- Una tipografía serif cálida y elegante para títulos destacados.
- Una tipografía sans-serif sencilla y legible para datos, botones y textos.

Se pueden utilizar DM Sans, Nunito o Inter para los textos y una serif como Lora para algunos encabezados.

## Ilustraciones

Crear una identidad ilustrada original:
- Montañas andinas.
- Parcelas agrícolas.
- Terrazas de cultivo.
- Árboles.
- Plantas de papa.
- Quinua.
- Maíz.
- Flores silvestres.
- Herramientas agrícolas.
- Pequeños animales de campo.
- Nubes y sol.

Las ilustraciones deben tener un estilo watercolor, hand-drawn y storybook, con colores naturales y trazos delicados.

No llenar todas las pantallas de dibujos. Utilizarlos como elementos decorativos que complementen las visualizaciones científicas.

Crear una barra lateral vertical fija, de color verde bosque oscuro, similar a la referencia.

En la parte superior colocar:

- Logotipo original PACHA PULSE.
- Una pequeña ilustración de montañas y cultivos.
- Texto: "Bienvenido a tu parcela".

Menú de navegación con iconos ilustrados:

1. Inicio.
2. Mi parcela.
3. Datos NASA.
4. Simulador agrícola.
5. Eventos climáticos.
6. Análisis del suelo.
7. Riego inteligente.
8. EcoGuard.
9. Simulador económico.
10. Reportes.

En la parte inferior:
- Ayuda.
- Configuración.
- Perfil del agricultor.

Agregar una pequeña ilustración original de un agricultor andino en la parte inferior de la barra lateral.

Debajo, incluir una sección llamada "Consejo del día", con consejos agrícolas breves.

# 4. ENCABEZADO PANORÁMICO

En la parte superior del dashboard colocar un encabezado panorámico ilustrado.

La ilustración debe representar un paisaje de la sierra de Junín:
- Montañas verdes.
- Campos agrícolas.
- Parcelas de papa y quinua.
- Pequeñas casas rurales.
- Árboles.
- Cielo despejado.
- Nubes suaves.
- Un pequeño agricultor trabajando.

El paisaje debe ocupar el ancho de la zona principal de contenido.

Sobre él debe aparecer un mensaje de bienvenida:

"¡Bienvenido de nuevo a PACHA PULSE!"

Debajo:
"Tu tierra tiene mucho que contar. Descubre cómo está tu parcela y prepara tu próxima cosecha."

En la esquina superior derecha:
- Fecha.
- Estación o temporada agrícola.
- Hora.
- Avatar ilustrado del agricultor.

# 5. DASHBOARD PRINCIPAL

Inspirarse directamente en la distribución de tarjetas de la imagen de referencia.

Organizar la pantalla mediante una cuadrícula visual de paneles con diferentes tamaños.

## Panel A: Resumen ambiental

Mostrar indicadores ilustrados:
- Temperatura.
- Precipitación.
- Humedad del suelo.
- NDVI.
- Estrés ambiental.

Cada indicador debe tener:
- Icono ilustrado.
- Valor de ejemplo.
- Unidad.
- Etiqueta descriptiva.
- Indicador de estado.

## Panel B: Mi calendario agrícola

Crear un calendario mensual ilustrado.

Mostrar:
- Fechas de siembra.
- Crecimiento.
- Fertilización.
- Monitoreo.
- Cosecha.

Utilizar pequeños iconos de plantas y herramientas para representar las actividades.

## Panel C: Alertas agrícolas

Mostrar alertas visuales sobre:
- Posible estrés hídrico.
- Riesgo potencial de heladas.
- Condiciones favorables para enfermedades.
- Cambios anormales de vegetación.

Cada alerta debe tener una categoría y un nivel de prioridad.

## Panel D: Mi parcela

Mostrar una pequeña vista ilustrada de un mapa agrícola.

Incluir:
- Límites de la parcela.
- Cultivos.
- Caminos.
- Ubicación.
- Indicadores de vegetación.

Agregar botón "Explorar mi parcela".

## Panel E: Mis cultivos

Crear pequeñas tarjetas ilustradas para:
- Papa.
- Quinua.
- Maíz.
- Cebada.
- Haba.
- Arveja.

Cada cultivo debe mostrar una fotografía o ilustración, su temporada y estado.

## Panel F: Actividades y progreso

Mostrar el avance de las actividades agrícolas mediante barras de progreso.

Ejemplos:
- Preparación del terreno.
- Monitoreo de cultivos.
- Revisión de humedad.
- Planificación de cosecha.

No convertir toda la plataforma en un juego: mantener una experiencia profesional.

# 6. MÓDULO MI PARCELA

Diseñar una pantalla donde el agricultor pueda visualizar sus terrenos.

Mostrar:
- Mapa satelital amplio.
- Nombre de la parcela.
- Ubicación geográfica.
- Superficie.
- Altitud.
- Pendiente.
- Tipo de suelo.
- Cultivo actual.
- Cultivo anterior.
- Disponibilidad de agua.

Crear una sección ilustrada denominada "Conoce tu terreno".

Utilizar mapas reales o representaciones visuales de Junín, pero distinguir claramente los mapas satelitales de las ilustraciones decorativas.

# 7. MÓDULO DATOS NASA

Diseñar una pantalla científica, pero manteniendo la identidad visual cozy de PACHA PULSE.

Mostrar:
- Temperatura histórica.
- Precipitaciones.
- Humedad del suelo.
- NDVI.
- Variaciones ambientales.
- Indicadores de estrés vegetal.

Incluir mapas de vegetación basados en Landsat.

Crear una sección llamada "Lo que nos cuentan los satélites".

Mostrar:
- Fuente de información.
- Fecha del dato.
- Periodo analizado.
- Variable observada.
- Descripción sencilla.

Los gráficos deben utilizar colores suaves y ser fáciles de interpretar.

# 8. MÓDULO SIMULADOR AGRÍCOLA

Esta es una de las funcionalidades principales de PACHA PULSE.

Crear una interfaz que permita experimentar visualmente con diferentes alternativas de siembra.

Diseñar un proceso dividido en cuatro etapas:

ETAPA 1: Seleccionar parcela.

ETAPA 2: Seleccionar cultivo.

Mostrar tarjetas ilustradas de papa, quinua, maíz, cebada, haba y otros cultivos compatibles con la región.

ETAPA 3: Simular escenarios.

Permitir visualizar diferentes posibilidades de siembra y rotación de cultivos.

ETAPA 4: Comparar resultados.

Mostrar:
- Compatibilidad climática.
- Necesidades de agua.
- Adecuación del suelo.
- Beneficios potenciales.
- Diversidad de cultivos.
- Riesgos agrícolas.

Diseñar tres tarjetas de comparación de escenarios.

Utilizar ilustraciones de los cultivos y gráficos comparativos.

# 9. SIMULADOR DE EVENTOS CLIMÁTICOS EXTREMOS

Diseñar una pantalla interactiva donde el agricultor pueda experimentar con cuatro escenarios:

- Sequía prolongada.
- Heladas.
- Exceso de precipitaciones.
- Olas de calor.

Cada escenario debe tener una ilustración representativa.

Incluir:
- Selector de intensidad.
- Duración del evento.
- Cultivo seleccionado.
- Impacto potencial.
- Rendimiento estimado.
- Vulnerabilidad.
- Estrategias de adaptación.

Mostrar una comparación entre condiciones habituales y escenario extremo.

Diseñar tarjetas visuales con colores que representen los diferentes niveles de riesgo.

# 10. ANÁLISIS DEL SUELO Y NUTRIENTES

Diseñar una pantalla dedicada a la salud del suelo.

Mostrar indicadores:
- Textura.
- pH.
- Carbono orgánico.
- Humedad.
- Riesgo de erosión.
- Necesidades nutricionales.

Incluir ilustraciones de:
- Raíces.
- Tierra.
- Microorganismos.
- Compost.
- Lombrices.

Agregar una sección llamada "¿Qué necesita mi suelo?".

Mostrar posibles recomendaciones:
- Compostaje.
- Cobertura vegetal.
- Rotación de cultivos.
- Abonos orgánicos.
- Mediciones adicionales.

Incluir una advertencia visual de que ciertos nutrientes, como fósforo y potasio, necesitan análisis de suelo y no pueden medirse directamente mediante satélites convencionales.

# 11. SIMULADOR DE RIEGO INTELIGENTE

Crear una pantalla donde el agricultor pueda experimentar con diferentes disponibilidades de agua.

Ejemplo destacado:

"¿Qué pasaría si dispongo de un 30% menos de agua?"

Incluir:
- Selector de disponibilidad hídrica.
- Precipitación.
- Agua de riego.
- Demanda del cultivo.
- Déficit estimado.
- Comparación entre cultivos.

Mostrar gráficos sencillos e ilustraciones de gotas de agua, nubes y plantas.

# 12. ECOGUARD — PLAGAS Y ENFERMEDADES

Diseñar una pantalla para la prevención de plagas y enfermedades.

Incluir:
- Catálogo ilustrado de plagas.
- Catálogo de enfermedades.
- Fotografías de hojas afectadas.
- Registro de observaciones.
- Alertas preventivas.
- Control biológico.
- Trampas.
- Manejo cultural.

Crear una sección llamada:

"Protege tu cultivo naturalmente".

Agregar un área visual para cargar una fotografía de una planta y mostrar una futura identificación mediante inteligencia artificial.

Utilizar como ejemplo una enfermedad de la papa, dejando claro que el resultado es ilustrativo.

Priorizar prácticas de manejo integrado de plagas y reducción del uso innecesario de pesticidas.

# 13. SIMULADOR ECONÓMICO

Crear una pantalla donde el agricultor pueda evaluar si conviene sembrar un cultivo.

Mostrar:
- Costos de producción.
- Semillas.
- Fertilizantes.
- Mano de obra.
- Riego.
- Transporte.
- Rendimiento esperado.
- Precio de venta.
- Ingresos estimados.
- Margen.
- Punto de equilibrio.

Incluir gráficos de comparación económica y escenarios optimista, moderado y desfavorable.

Permitir visualmente la edición de precios y costos locales.

# 14. REPORTES

Diseñar una sección para visualizar informes de la parcela.

Mostrar:
- Resumen ambiental.
- Historial de cultivos.
- Comparación de rotaciones.
- Escenarios climáticos.
- Salud del suelo.
- Análisis económico.
- Riesgos agrícolas.
- Recomendaciones.

Crear una vista previa elegante de un reporte PDF.

# 15. ACCESIBILIDAD

La plataforma debe ser fácil de utilizar por agricultores con diferentes niveles de alfabetización digital.

Considerar:
- Botones grandes.
- Texto legible.
- Iconos acompañados de etiquetas.
- Contraste adecuado.
- Navegación sencilla.
- Lenguaje claro.
- Adaptación a dispositivos móviles.
- Compatibilidad con lectores de pantalla.
- No utilizar únicamente colores para transmitir riesgos o estados.

# 16. COMPORTAMIENTO DEL PROTOTIPO

IMPORTANTE: esta primera versión debe ser exclusivamente un prototipo de diseño visual.

No implementar:
- APIs reales.
- Datos reales de NASA.
- Machine Learning.
- Algoritmos agrícolas.
- Bases de datos.
- Predicciones reales.
- Autenticación real.
- Cálculos económicos o agronómicos reales.

Se permite:
- Navegar entre pantallas.
- Abrir menús.
- Cambiar pestañas.
- Mostrar ventanas emergentes.
- Utilizar selectores visuales.
- Simular interacciones.
- Mostrar gráficos con datos ficticios claramente identificados.

# 17. RESULTADO FINAL ESPERADO

La plataforma debe sentirse como una combinación entre:

- Un videojuego cozy de gestión de naturaleza.
- Una plataforma moderna de agricultura inteligente.
- Un dashboard científico de observación terrestre.
- Una herramienta intuitiva para agricultores.

La pantalla principal debe recordar la composición de la referencia proporcionada: barra lateral verde, encabezado panorámico ilustrado, tarjetas crema y pequeñas ilustraciones.

Sin embargo, toda la identidad debe ser original y representar la agricultura andina peruana.

**Prioridad absoluta: conservar la estética ilustrada, cálida y acogedora de la referencia en TODAS las pantallas, sin perder la claridad y profesionalismo de una plataforma tecnológica.**

No crear solamente una landing page. Diseñar toda la experiencia visual de PACHA PULSE.
